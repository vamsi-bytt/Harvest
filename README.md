# 🍓 Harvest – Fresh Fruit E-Commerce

Harvest is a modern fruit e-commerce platform offering fresh fruit slices, delicious fruit bowls, and convenient fruit packages. Browse products, add to cart, place orders, and enjoy fresh fruit delivered straight to your doorstep.

## ✨ Features

- 🍉 Browse fresh fruit slices and fruit bowls.
- 🥗 Explore different fruit packages and combinations.
- 🛒 Add products to the shopping cart.
- 📦 Convenient ordering and delivery experience.
- 📱 Responsive design for desktop and mobile devices.
- 🎨 Clean and user-friendly interface.

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Vite
- Lucide React

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd harvest
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
